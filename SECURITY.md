# Kebijakan keamanan

InpaCare adalah aplikasi pembelajaran dengan data demo sintetis. Perbaikan diterapkan pada cabang `main`. Proyek belum memiliki rilis produksi yang didukung atau jaminan waktu tanggapan.

## Laporkan kerentanan

Laporkan secara privat melalui GitHub. Sertakan kode atau endpoint terkait, langkah reproduksi dengan data sintetis, hasil yang diharapkan, serta dampaknya. Bagikan bukti secukupnya. [Pelaporan privat GitHub](https://github.com/Malwildan/inpacare/security/advisories/new)

Gunakan instans lokal untuk pengujian. Jaga kerentanan tetap privat hingga pengelola membahas perbaikan. Keluarkan kuki sesi, token akun, informasi pasien, kredensial basis data, dan dokumen privat dari laporan.

Akun dan kata sandi yang tercantum pada demo hanya untuk data sintetis. Simpan rahasia runtime dalam berkas konfigurasi di luar Git dengan akses khusus pemilik.
